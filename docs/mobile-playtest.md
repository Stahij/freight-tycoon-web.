# Тестирование Freight Tycoon Web 0.1.0 на телефоне

## Публичный запуск

После успешного завершения GitHub Actions откройте адрес Pages, указанный в разделе Settings → Pages или в карточке запуска workflow Deploy Freight Tycoon Web to GitHub Pages. Не считайте сайт опубликованным, пока адрес не открывается по HTTPS.

## Быстрая проверка на Android

1. Откройте публичный адрес в Chrome.
2. Проверьте, что отображается панель Freight Tycoon, баланс и контракты.
3. Примите один доступный контракт.
4. Нажмите «Следующий день» несколько раз и проверьте продвижение рейса, расходы и выплату.
5. Обновите страницу: сохранённое состояние должно восстановиться в том же браузере.
6. Проверьте меню, разделы «Контракты», «Автопарк» и «Финансы» на узком экране.

## Известные ограничения 0.1.0

Это ранний браузерный прототип. Данные сохраняются локально в браузере; синхронизации между устройствами и облачного сохранения нет. Экономика и скорость рейсов упрощены.

## Диагностика публикации

Workflow .github/workflows/pages.yml сначала выполняет npm run check, npm run build и npm test, а затем публикует статические файлы в GitHub Pages. Если публикация не появляется, проверьте завершение обоих заданий и настройку Settings → Pages → Build and deployment → Source: GitHub Actions.
